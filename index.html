Train Pre-Check Active

Module 2 Output: Railway Track Obstacle Scanner

Real-time computer vision algorithm scanning tracks for trespassers, livestock/animals, or debris, drawing bounding boxes and sounding emergency cab alarms.

ANPR E-Fine Active

Module 3 Output: Gate Violation ANPR & Automated E-Mail Fine Dispatch

When level-crossing gate barriers are lowered, vehicles attempting to bend under or force through the gate trigger ANPR OCR. The captured license plate queries the vehicle registry, locates the owner's registered email ID, and automatically dispatches an E-Fine invoice to pay.

Eye Aspect Ratio Monitor

Module 4 Output: Locopilot Real-time Drowsiness Alert

Continuous webcam feed inside the driver's cabin tracking Eye Aspect Ratio (EAR) and head tilt to trigger high-decibel acoustic alarms if fatigue is detected.

import pyttsx3

def get_bus_crowd_status(passenger_count):
    if passenger_count < 15:
        return {"status": "Seats Available", "color": "#10b981", "badge": "🟢 GREEN"}
    elif passenger_count <= 35:
        return {"status": "Light Crowd", "color": "#f59e0b", "badge": "🟡 YELLOW"}
    else:
        return {"status": "Overcrowded", "color": "#ef4444", "badge": "🔴 RED"}

def send_disabled_pickup_request(udid_id, bus_no, stop_name):
    engine = pyttsx3.init()
    engine.say(f"Request sent to bus {bus_no} at stop {stop_name}")
    engine.runAndWait()
    return {"driver_action": "PENDING_CONFIRMATION", "udid": udid_id}
